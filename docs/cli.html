INTERFACES / CLI REFERENCE

The command line, completely.

Use these commands in scripts, CI jobs, and local experiments. Read-only commands never modify your data; build commands write only to the output paths you provide.

datadoc --helpCSV + ParquetJSON artifacts
Start with profile →

Read-only commands

PROFILEdatadoc profile <file>

Inspect schema, nulls, duplicates, cardinality, roles, findings, and the schema fingerprint.

Terminaloptional target + output
datadoc profile data.csv \
  --target churn \
  --output profile.json
PLANdatadoc plan <file>

Generate operations and rationales without applying transformations.

Terminalreview before fit
datadoc plan data.csv \
  --target churn \
  --task classification \
  --drop-identifiers \
  --output plan.json

Build commands

FITdatadoc fit <train>

Learn train-only state and save a reusable pipeline artifact.

Terminaldefaults are safe
datadoc fit train.csv \
  --target churn \
  --task classification \
  --scaling auto \
  --output artifacts/pipeline.json
TRANSFORMdatadoc transform <file>

Apply a saved artifact to validation, test, or inference data. The pipeline must already be fitted.

Terminalschema checked before write
datadoc transform validation.parquet \
  --pipeline artifacts/pipeline.json \
  --output validation-features.parquet
EXPORTdatadoc export

Write a small Python wrapper around the fitted artifact for transparent deployment.

Terminalreproducible wrapper
datadoc export \
  --pipeline artifacts/pipeline.json \
  --output pipeline.py

Measure commands

EVALUATEdatadoc evaluate <file>

Compare a baseline and candidate with optional ordered or group-aware splitting. Install the ML extra first.

Terminalclassification
python -m pip install "datadoc-cli[ml]"
datadoc evaluate train.csv \
  --target churn \
  --task classification \
  --estimator linear \
  --output evaluation.json
Regression

Use --task regression. The primary metric is RMSE, with the report exposing a negative-RMSE comparison so higher is better internally.

RUNdatadoc run <file>

Run profile, plan, fit, transform, and manifest generation in one local directory. Add --evaluate when a target and ML extra are available.

Terminalguided workflow
datadoc run data.csv \
  --target churn \
  --task classification \
  --output-dir runs/churn-v1 \
  --evaluate

Compatibility commands

The original commands remain available while users migrate: analyze, recommend, engineer, compare, visualize, report, pipeline, plugin, ui, and agent.

Use the new commands for production.

engineer is a deprecated convenience path because a mutable one-step operation makes train/test boundaries easy to misuse. New code should use fit and transform.

OptionWhereMeaning
--targetprofile, plan, fit, evaluate, runProtects the supervised label.
--taskplan, fit, evaluate, runauto, classification, or regression.
--scalingfitauto, none, standard, or robust.
--clip-outliersfitOpt into IQR clipping.
--time-columnevaluateUse ordered splits rather than random shuffling.
--group-columnevaluateKeep groups separated across splits.

CLI error recovery

Missing required columns

Inspect pipeline.json → input_schema. The transform file must contain every required feature column; extra columns are harmless only when the artifact contract allows them.

Unsupported output extension

Use a path ending in .csv, .parquet, or .pq.
