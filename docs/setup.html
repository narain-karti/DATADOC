SETUP & INSTALLATION ⇱

DATADOC is published on PyPI as datadoc-cli. Requires Python 3.9+.

1. Install via pip

$ pip install datadoc-cli

2. Install via uv (Recommended for speed)

$ uv pip install datadoc-cli

3. Environment Variables (Optional for AI Orchestration)

If using the --ai flag or doc.ai_engineer(), create a .env file in your working directory:

DATADOC_MODEL=groq/llama-3.3-70b-versatile
GROQ_API_KEY=gsk_your_groq_api_key
GEMINI_API_KEY=AIza_your_gemini_api_key
CLI COMMAND CHEATSHEET ⇱

Run these high-impact commands directly from your terminal:

  • 01 datadoc analyze raw_data.csv Generates full diagnostic health report
  • 02 datadoc recommend raw_data.csv Shows recommended plugin transformations
  • 03 datadoc engineer raw_data.csv Executes full automated cleaning & exports clean CSV
  • 04 datadoc compare raw_data.csv clean.csv Displays visual side-by-side terminal comparison
  • 05 datadoc pipeline raw_data.csv Exports reproducible Python source code file
  • 06 datadoc chat raw_data.csv Interactive agentic AI chat session
