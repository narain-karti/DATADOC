The Leakage-Safe Pipeline

DATADOC operates as a deterministic, stateful machine learning pipeline. Instead of modifying data arbitrarily, it separates learning (fit) from applying (transform). During the Fit Phase, it detects column roles and learns statistics (like median values or IQR boundaries) strictly from the training dataset. These learned rules are serialized into a JSON artifact. During the Transform Phase, it strictly applies those exact frozen rules to unseen data to guarantee zero test-set leakage.

Key Architectural Guarantees

  • 🔍 COLUMN ROLE SENSITIVITY

    Detects unique sequence integers, names, and UUIDs to drop them automatically. Prevents invalid scaling on ID variables.

  • ⚡ POLARS RUST BACKEND

    Processes millions of rows in memory using multi-threaded Rust execution for maximum throughput and minimal RAM usage.

  • 🛡️ ZERO DATA LEAKAGE

    Imputation and scaling statistics are strictly learned only on training data and locked, guaranteeing zero test-set leakage.

  • ⚙️ 100% REPRODUCIBILITY

    Generates equivalent JSON artifacts (pipeline.json) so your data engineering is fully portable and audit-ready.
