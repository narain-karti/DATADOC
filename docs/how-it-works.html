ARCHITECTURE OVERVIEW ⇱

The Plugin Orchestrator

DATADOC operates as a deterministic, high-speed dataset engineering orchestrator. Instead of modifying data arbitrarily, it runs raw datasets through a strict sequence: first, **Column Role Detection** filters out non-predictive columns; next, an isolated chain of priority-ordered plugins transforms the remaining features.

Key Architectural Guarantees

  • 🔍 COLUMN ROLE SENSITIVITY

    Detects unique sequence integers, names, and UUIDs to drop them automatically. Prevents invalid scaling on ID variables.

  • ⚡ POLARS RUST BACKEND

    Processes millions of rows in memory using multi-threaded Rust execution for maximum throughput and minimal RAM usage.

  • 🛡️ ZERO DATA LEAKAGE

    Imputation and scaling statistics are strictly evaluated to prevent test-set leakage or artificial distribution warping.

  • ⚙️ 100% REPRODUCIBILITY

    Generates equivalent Python source code (doc.pipeline()) so your data engineering is fully audit-ready.
